구현 현재

  • Node.js · Express REST 서버, Redis 세션은 선택(미연결 시 자동 폴백)
  • vLLM 미구축 환경 제약 → 규칙 기반 해석기로 GPU 없이 동일 흐름 시연
  • 보정 엔진: 경로 교차·spawn-goal 거리·구역 겹침·개수·범위를 계약대로 복구, 같은 입력에 항상 같은 출력
  • 검증: 자동 테스트 98건 + 무작위·적대 입력 20,000건 예외 0

역할 전환 계획

  • 현재는 LLM 모듈이 1차 보정, 백엔드가 계약 기준으로 재검증
  • LLM 모듈의 보정 단계가 빠지면 백엔드가 보정·검증을 전담
  • 실제 vLLM 출력 수집 → 회귀 테스트셋 구축, 보정 규칙 재조정
  • 대화의 난이도 의도(상승·하강·중반 고비)를 받아 곡선 형태 보장
