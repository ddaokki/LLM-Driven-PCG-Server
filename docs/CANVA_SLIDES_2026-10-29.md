## 슬라이드 9 — 제목

백엔드 모듈 - dialogue → Zone 파이프라인 및 장애 허용

## 슬라이드 9 — 본문

후보 생성 (vLLM → 규칙 기반 폴백):
dialogue를 받아 vLLM(OpenAI 호환, JSON Schema 강제)로 Zone 후보를 생성. 실패·타임아웃이면 규칙 기반 해석기(테마·밀도·길 모양·전투 수·강도·크기 추출, seed 재현)로 폴백 → GPU 없이도 "대화가 바뀌면 존이 바뀌는" 시연 가능

언리얼 10/27 계약 반영:
Area PCG 액터 자동 생성으로 개수 제약 해소. 모든 combat 클리어 시 goal 활성화 → combat 개수 강제와 난이도 순서가 플레이 흐름과 직결

Redis 장애 허용:
미연결이어도 /generate-zone 정상 동작(10초 백오프). 연결 시 이전 배경·최근 대화를 LLM 프롬프트에 주입해 서사 연속성 유지

검증:
자동화 테스트 98건(명세 BE-T01~T12 포함), 무작위 입력 2,000건 + 적대 입력 18,000건에서 예외 0·멱등 위반 0. npm run test:report로 결과서(md/docx) 자동 생성

## 슬라이드 10 — 제목

백엔드 모듈 - 레이아웃 정합성 보정 엔진 (validator v3)

## 슬라이드 10 — 본문

경로 기하 보정 (path geometry):
근접점 병합, 2-opt 자기교차 해소, 급회전(<25°) 완화, spawn-goal 최소 직선거리 0.45 확보. 복구 불가면 기본 경로

경로-구역 결합 및 진행도 정렬:
spawn/goal을 경로 양끝에 스냅, combat은 경로 근접(가장자리 ≤0.12). x좌표 대신 호길이 진행도로 정렬해 배열 순서 = 경로상 순서 보장

간격·겹침·테마·난이도:
경로 좌표계 1D 간격 풀이(인접 ≥0.06), 반지름 축소로 2D 겹침 0, 테마 4종(forest/grassland/desert/snow) 밀도 프로필, 전투 강도 진행 방향 단조 증가

결정적·멱등 + 보정 리포트:
난수 없음, validate(validate(x)) = validate(x). ?debug=1이면 단계별 before/after/사유와 품질 점수 반환 (tanh 소프트 클램프는 멱등성과 양립 불가라 제거)
